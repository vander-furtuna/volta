# Plano do hackathon

Hackathon de Inovação Aberta FEJECE × Cardápio Web 2026. Squad de 4 a 6 pessoas de pelo menos duas empresas juniores, com pelo menos uma pessoa de desenvolvimento web ou UX e uma de negócios.

## Datas

| Data  | Marco                                                             |
| ----- | ----------------------------------------------------------------- |
| 18/11 | Mentoria #4: métricas e cortes de escopo                          |
| 19/11 | Exceções, acessibilidade, ensaio da demo, documentação            |
| 20/11 | Congelar código e enviar entregáveis com folga                    |
| 21/11 | Pitch no IMPACTE'26 (5 min de apresentação + 10 min de perguntas) |

## Critérios (20% cada)

| Critério               | Evidência que vamos mostrar                                                         |
| ---------------------- | ----------------------------------------------------------------------------------- |
| Aderência ao desafio   | Problema de promoções sem medida, com recompra como consequência                    |
| Inovação               | Público explicável, custo máximo antes de criar, resultado em três camadas          |
| Qualidade do protótipo | Fluxo completo em código, integrado ao sandbox da CW, com exceções tratadas         |
| Modelo de negócios     | Assinatura pela CW App Store, taxa de 20%, ponto de equilíbrio com premissas claras |
| Pitch                  | Demo reproduzível no modo demonstração e limitações assumidas                       |

Só são avaliados projetos com protótipo funcionando e apresentação.

## Entregáveis

- [ ] Repositório com código e instruções de execução
- [ ] Protótipo navegável (deploy na Vercel)
- [ ] Modelo de negócios ([canvas](https://claude.ai/artifact/R16xt2x7JBqZpi4oAomaY8))
- [ ] Apresentação em PDF
- [ ] Roteiro da demo testado em desktop e celular
